# KTW Bestandscheck

Digitale Bestands-Checkliste der KTN Krankentransport Nord GmbH für die iPads der KTW.

- App: `index.html` (wird über GitHub Pages bereitgestellt)
- Absenden erzeugt eine CSV-Datei, die über das Teilen-Menü in luckycloud (Ordner „Eingang“) gespeichert wird.
- Der automatische Abgleich mit dem Bestandsverzeichnis läuft auf dem Rechner der Geschäftsführung.

Die Dateien werden automatisch erzeugt – bitte nicht von Hand bearbeiten.
